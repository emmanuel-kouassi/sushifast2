SushiFast – TP React

## Description du projet

SushiFast est une application web développée avec React pour TP
Elle permet d’afficher une liste de menus de sushis et d’appliquer différents filtres afin de retrouver facilement les menus correspondant à certains critères (aliments, saveurs, etc.).

Les données des menus sont stockées localement dans un fichier JSON.

---

Languages utilisés
- React (Vite)
- JavaScript
- React Router DOM
- Bootstrap
- HTML / CSS
